How it works
One wrapper. Full visibility.
No proxy, no account, no data leaving your machine. Trace instruments your existing LLM client locally.
1

Wrap your client

One line change. Your API calls, models, and logic stay exactly the same.

const openai = trimwares.openai(new OpenAI())
2

Make LLM calls

Trace logs token attribution, costs, cache hits, and latency to a local file. Never the prompt text.

.trimwares/session.jsonl
3

See the report

Terminal report with free tier. Pro unlocks a live local dashboard with 30-day history, model breakdown, and alerts.

npx trimwares serve
